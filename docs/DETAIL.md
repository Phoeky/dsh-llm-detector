# 模型指纹检测

让模型凭第一反应写约 300 个 1–355 的整数，再把它的数值分布与冻结的参考库比对，给出
“这个渠道背后最像哪个模型”的排名。检测经 DSH 的 `llm` 服务发出，使用当前 profile
已配置的 provider、认证与适配层。

## 提供的工具

`llm_fingerprint`

- `action: list`：列出已注册的 provider；指定 `provider` 时列出其模型目录。
- `action: detect`：对指定或默认模型采样并评分，返回每轮排名、置信度、序列检查与样本诊断。

## 行为

- 每轮生成 3 道挑战，长度 292–332 不重复，语言独立随机。
- 流式接收；收到要求数量的完整整数即停止（宽松截断），有效数字不足或未正常结束的样本被拒绝。
- 三条有效回答才给校准置信度；一两条只给排名。
- 结果是参考库内的闭集排序。库外模型也会得到候选，置信度不代表身份证明。
- 每次检测默认发生 3 次真实模型调用，按渠道计费；串行发送，单条最长 240 秒。

## 限制

- 参考库以文字提示词、裸 API 采集；DSH 适配层注入的系统提示可能让结果偏离。
- 同源、蒸馏或共用分词器的模型可能互相混淆。
- 不含分词器探测与图片模式。
